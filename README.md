# AI Catalog Generator

AI Auto Category and Tag Generator built using Flask and AI technology.  
This tool helps automatically generate product categories and tags for catalog items.

## Live Demo
https://ai-catalog-generator.onrender.com

## Project Overview
The AI Catalog Generator is a web-based application that helps users automatically generate product categories and tags using artificial intelligence. It simplifies catalog management for businesses by reducing manual work and improving product organization.

## Features
- AI-powered category generation
- Automatic tag generation
- Simple and user-friendly interface
- Fast response using Flask backend
- Web-based application

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- AI API

## How to Run the Project

1. Clone the repository
```
git clone https://github.com/shrikantkumarofficalin-cyber/ai-catalog-generator.git
```

2. Install dependencies
```
pip install -r requirements.txt
```

3. Run the application
```
python app.py
```



4. Open in browser
```
http://127.0.0.1:5000
```

## Test Example

To test the Product Category Generator, enter the following sample input:

Product Name: Wireless Bluetooth Headphones

Description: High-quality wireless headphones with noise cancellation and long battery life.

Click **Generate**.

The system will automatically generate the appropriate product **category and tags** based on the provided information.
